Work

These games were learned at the table by playing them. I think game culture is worth preserving, so I started these projects and saw them through. Now groups with nobody to explain the rules can learn and play them too. The first three are online, free and ad-free. Click and try. The DG Android app is available to testers.

Jako

Nine traditional card games in the browser, against computer opponents.

I learned five of the nine in a group that played every day. The richness of card games lies in local rules, so there is no single correct version, only variants to choose from. The default settings were chosen for playability.

React · JavaScript · Vite · Vercel

  • The computer opponents' levels were measured by letting the computer play against itself, 400 games for each pair of levels
  • The measurement showed that in two games the level makes no difference to the outcome. The player is told so, instead of being promised a difference that does not exist

Itu

A word-building game in Finnish.

It is modelled on a letter dice game where sand running through an hourglass measured each turn. Itu gives bonus points for using nearly all the letters before time runs out. There was no dictionary at the table: whether a word counted was settled by a shared sense of the language. When you play alone there is nobody to argue with, so in Itu the judge is the official word list of the Institute for the Languages of Finland (Kotus).

TypeScript · Vite · Vercel

  • The word list and its inflected forms are compressed to fit in the browser, so no server is needed
  • Scoring, word checking and the compression of the word list are covered by automated tests, which run before every change is saved

Superjatsi

A dice game with five or six dice.

For the all-round player of the classic five-dice scoring game. The six-dice version is rarely played at the table, and now it is available. A game takes about 20 minutes.

Web Components · TypeScript · Vercel

  • The scoring rules are covered by automated tests, and two of them play 500 games through and check that the rules do not contradict each other
  • Built with the browser's own tools, without a UI library

DG Android

An Android app for the DailyGammon backgammon service.

DailyGammon is not played against the clock: you have days for each move and a tournament can last years. The app is made for that rhythm. It reminds you of moves waiting for you and keeps the match conversation, which the service deletes as soon as a message has been read.

Kotlin · Jetpack Compose

  • Reading the service's pages is separated from the app into its own module, so it is tested against saved pages without a phone or an emulator

How I work

  • I measure before I claim. A first experiment of 30 games showed three clear difficulty levels in the card games. A larger experiment of 400 games overturned it, so I did not promise a feature that did not exist.
  • I also report what did not work. A null result is information just like a success, and hiding it costs more later.
  • I take in outside code only when it pays off. Every library is a promise someone else can break with an update, so I weigh each one separately.
  • I say where information comes from. If I do not know, I leave the item blank rather than guess.
  • I reduce loss in communication. The more precisely I say what I mean, the less room there is for guessing. That applies equally to specification, naming and directing AI.

I write these projects with Claude Code. It is not a chat window you paste code into but an agent that reads the whole repository, edits files, runs the tests and commits. A work session is a conversation with it: I say what I want and why, it proposes and implements, and I read, ask and reject. When the same rule comes up a third time, it is written into the project's instruction file, which the agent reads at the start of every session. The way of working is itself versioned: rules, game specifications and rejected ideas are in git just like the code, for example Jako's instruction file and measurement log, which records for every experiment what was tested, how many times and what followed. Both are in Finnish. If you wonder whether work done this way stands up to scrutiny, do not take my word for it but read them.

I work with the AI in Finglish, Finnish mixed with English technical terms. It started with Jako, where the rules of the card games first had to be put into words. Many of those words had no obvious English counterpart. As our shared vocabulary grew, less room was left for guessing, and guessing is exactly where AI goes wrong. A misunderstanding always costs more than the choice of language saves.
